# Luganda Translator

A small desktop app built with Python's Tkinter. It uses a built-in English-to-Luganda dictionary for common words and phrases; text that is not in the dictionary stays unchanged.

## Run the app

On Windows, open PowerShell in this folder and run:

```powershell
py -3 lugandatranslator.py
```

Type text into the top box and select **Translate**. You can also press **Ctrl+Enter**. Select **Clear** to start over.

Add or edit words in `WORD_DICTIONARY` and phrases in `PHRASE_DICTIONARY` in `lugandatranslator.py`.

This is a simple learning project, not a full sentence-translation service.
